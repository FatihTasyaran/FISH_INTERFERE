FISH callback execution stats

Per-callback fire counts per hyperperiod window — mean / std / min / max column guide ▾
Source: how the period was derived (tmr-nominal drives H; sub / serv have no own period). Period: the OWN period of the row (timers only); the dash on subs/services is correct, not missing data. N fires: total executions in the session. Htmr: the executor timer hyperperiod = window size for the EX stats (repeats on every row of that executor; on service rows it can be mistaken for a period - it is not one). μ/σ/min/maxEX: fires per Htmr window, over the windows between the first and last firing of the callback (interior silent windows count as 0). μ/σ/min/maxsess: the same statistic with the session-wide timer LCM as the window.
Why minsess = maxsess sometimes: when Hsession is longer than the session itself (LCM explosion of many near-coprime periods - the Autoware case: Hsession = 3.3M s vs a 408 s run) only one window exists, so μ=min=max and σ=0. The EX and session groups carry the same numbers only when Htmr = Hsession (single-executor sessions such as the Isaac benchmarks).
