# Autoware run scripts (fresh container, container_install route)

All scripts start a FRESH container from `autoware-dev-trt-a1000-fishwait5`
(image never modified), `docker cp` the current `fish_interfere` in, re-run
`install_fish.sh`, patch `fish_settings.ini` in the container, then `ros2 launch`
through the FISH wrapper. Traces land in `~/fish_traces/`.

| script | scenario | notes |
|---|---|---|
| `run_logging_sim_bag.sh` | logging_simulator + sample-rosbag 0.5x | r11 = cp_0 (notes/cp_0.txt) |
| `run_planning_sim_goal.sh` | planning_simulator + initial pose + goal + autonomous | r18 = cp_1 (notes/cp_1.txt); pose/goal files `psim_init.txt`, `psim_goals.txt` (sample-map-rosbag lanelet 1) |
| `run_awsim_e2e.sh` | e2e_simulator against AWSIM (Unity in a second container, `-batchmode -nographics`) | r17 state; blocked by NDT vs map (notes/about_docs/awsim_setup.txt); goal candidates `goal_cands.json` / `goal_calls.txt`, AWSIM config `awsim-min-config.json` |
