## Proposed additions (B1)
- rclcpp: publish_link in do_loaned_message_publish and do_serialized_publish (+ GenericPublisher) — 2 lines.
- rcl: TRACEPOINT in rcl_take_loaned_message / rcl_take_serialized_message / rcl_take_sequence — new FISH TP
  `fish_rcl_take_variant(subscription, kind, source_timestamp)` or reuse rmw_take semantics via rcl.
- rmw level (apt binaries): kernel userspace-probe on rmw_take_loaned_message_with_info if the rcl TP is not enough.
- Enable rclcpp_intra_publish + rclcpp_ring_buffer_dequeue in per_instance (task A2).
- WaitSet: TRACEPOINT around WaitSetTemplate::wait returns + the app's own dispatch cannot be seen; document as limitation.

## Added 2026-10-05 (fishwait24 — probes for node-internal data flow; all OFF unless enabled with FISH_EXTRA_EVENTS)
Generated by Claude Fable 5.1 (Anthropic). Patch: docker/overlay_patches/fishwait24_state.py; lock shim: fish_lock_shim.c
(+ test_lock_shim.sh); consumer: postprocess/state_links.py; campaign: scripts/state_probe_campaign.sh.
| event | where | what it gives |
|---|---|---|
| ros2:fish_msg_retain(subscription_handle, message, refs) | rclcpp Executor::execute_subscription, after the callback returns | the callback kept a reference to its message (deposit by pointer / queue) |
| ros2:fish_msg_release(subscription_handle, message) | deleter of the message alias, in the thread that drops the last reference | inside callback X → X consumed it (queue) or X is the next deposit (overwrite) |
| ros2:fish_msg_type(handle, is_pub, size, stamp_off, n_ids, type_name, id_paths) | rmw_cyclonedds, once per rmw publisher / subscription | struct size (pointer identity), where the typed identity fields are |

| ros2:fish_lock(callback, mutex, site, n, hold_sum, hold_max, wait_max, flags) | libfish_lock_shim.so (LD_PRELOAD, FISH_LOCK_SHIM=1), end of each callback instance | application mutexes of the instance: count, critical-section length, wait |
| ros2:fish_lock_site(site, offset, object, symbol) | same, once per application call site | which library / function takes the lock |
Not probed: /clock, /parameter_events, /rosout (every node takes them; rclcpp's TimeSource keeps the last /clock message —
98 % of the retention and 93 % of the stamp events of the first run). Exception: the PUBLISHER of /clock is stamped (one
event per tick, serialized publishes read from the CDR buffer) — under simulated time a stamp equal to a tick identifies
no message, and state_links.py needs the tick values to tell. Not covered: intra-process deliveries (header
templates → application rebuild), serialized / loaned takes, rwlocks, Time / UUID members inside sequences.
`bool ros_trace_fish_enabled(which)` lets a probe skip its work while its event is off.
